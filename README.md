Løsning til øvelserne i [RACE 8 · Thinking in React](https://cederdorff.com/wu-e26a/react-intro/).

Hver øvelse har sin egen branch. Branchen viser projektet, som det ser ud, når øvelsen er løst. Klik på "diff" for kun at se det, der er nyt i den øvelse.

## Kør en løsning

```bash
git clone https://github.com/cederdorff/my-first-react-app.git
cd my-first-react-app
git switch ovelse-11b-state
npm install
npm run dev
```

Skift `ovelse-11b-state` ud med den øvelse, du vil se.

Prøv selv først. Brug løsningen, når du sidder fast, eller når du vil sammenligne med din egen.
